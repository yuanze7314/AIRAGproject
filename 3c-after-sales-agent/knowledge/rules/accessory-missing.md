# AirBuds Pro X 配件缺失处理规则

AirBuds Pro X 标准包装通常包含耳机本体、充电盒、USB-C 充电线、三组耳塞、快速指南和保修说明。用户反馈缺少耳塞、充电线、说明书、保修卡或活动赠品时，应先核对订单版本、商品详情页、活动页面和开箱凭证。

需要用户补充：订单截图、开箱照片或视频、包装盒内物品照片、商品详情页或活动页说明。若涉及直播间赠品，应同时要求直播截图、活动页或录屏等承诺凭证。

不得直接确认缺件，不得直接承诺补发。只能说明会根据订单版本、页面说明和凭证进一步核实。

禁止承诺：确认缺件、直接补发、一定赔付。
