# AirBuds Pro X 质量问题处理规则

用户反馈 AirBuds Pro X 出现杂音、电流声、单边无声、蓝牙频繁断连、主动降噪异常、充电盒无法充电、续航明显异常等疑似质量问题时，应先安抚并引导补充凭证。

需要补充的信息包括：订单信息、购买时间、问题出现时间、问题发生场景、是否更换设备测试、耳机和充电盒实拍图、录音或视频凭证、平台要求的检测或售后凭证。

不得仅凭用户描述直接确认 AirBuds Pro X 存在质量问题，不得直接承诺退款、赔付、补发或审核通过。应说明会结合订单、商品状态、凭证和平台规则进一步核实，最终结果以平台审核为准。

建议回复：理解用户体验受影响，说明需要核实杂音/断连/降噪异常等具体现象，引导补充订单和故障凭证，并明确暂不能直接承诺退款或赔付。

禁止承诺：确认质量问题、可以退款、可以赔付、一定补发、一定审核通过。
