# Architecture Decision Log

## 2026-06-12

- Architecture stage created from PRD and product brief.
- Decision: Use a single full-stack Web Demo for MVP instead of distributed services.
- Decision: Use modular Agent Pipeline boundaries so RAG, Vision, Memory, Strategy, Reply, and Guardrail can be replaced independently later.
- Decision: Use local Markdown/JSON rules for MVP RAG.
- Decision: Use multimodal model output only as auxiliary evidence, never final adjudication.
- Decision: All generated replies must pass Safety Guardrail before display.
- Decision: Badcase storage starts local, with export-friendly structure.

- Decision: Upgrade architecture from single Agent Pipeline to 4-Agent orchestration: Case Understanding, Policy & Evidence, Risk & Decision, Reply & QA.

- Decision: Upgrade from 4-Agent sequential architecture to 5-Agent orchestration: Case Understanding first, Policy & Evidence and Risk & Strategy in parallel, Reply generation, independent QA gate with rewrite loop.
